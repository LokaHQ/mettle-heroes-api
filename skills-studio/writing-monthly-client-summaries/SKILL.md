# Writing monthly client summaries

## Instructions

1. Find the named client in the account file (seats, plan, included hours, start and end date) and in the month's hero-hours usage file (included hours, hours used this month and last month).
2. Find every support ticket for that client in the month's ticket file.
3. Write the summary in four sections, in this order:
   - **Headline**: two or three sentences on the state of the account this month. Lead with the thing that most needs attention, or say plainly that there's nothing to flag.
   - **Hero-hours this month**: a small table with included hours and hours used. State the percentage of included hours used. If hours used is more than included hours, say so in words, not just the numbers.
   - **Tickets this month**: list each ticket by id and one line of context. If a ticket is still open, name it as open. If none were raised, say so.
   - **What's next**: any open ticket, any contract end date within 60 days, and the next scheduled touchpoint if nothing else is outstanding.
4. Write for the client's own contact, not for Mettle & Co's internal team: direct, factual, no internal shorthand.
5. Every figure must come from the files. If something isn't in the files, write "not found" rather than guessing.
