# Writing monthly client summaries

## Instructions

1. Find the named client in the account file and in the month's hero-hours usage file.
2. Find every support ticket for that client in the month's ticket file.
3. Write the summary in four sections, in this order:
   - **Headline**: two or three sentences on the state of the account. Lead with what most needs attention, or say plainly that there's nothing to flag.
   - **Hero-hours this month**: a small table with included hours and hours used, and the percentage of included hours used. Compare this month with last month in one line. If hours used is more than included hours, say so in words.
   - **Tickets this month**: each ticket by id with one line of context. Name every ticket that is still open. If none were raised, say so.
   - **What's next**: each open ticket, any overage, and the next scheduled touchpoint if nothing else is outstanding.
4. Write for the client's own contact, not for Mettle & Co's internal team: direct, factual, no internal shorthand.
5. Every figure must come from the files. If something isn't in the files, write "not found" rather than guessing.
