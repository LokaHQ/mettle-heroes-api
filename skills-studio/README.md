# Skills Studio materials

Everything a Skills Studio participant needs: the practice data, the finished skill, and the templates the course leaves running. Download this folder (or the whole repository as a zip) rather than asking anyone for files from the internal course-build repository.

- `mettle-accounts/`: Callum Reid's client book for December. `customers.csv` is the account list, `hero-hours-2026-12.csv` is hero-hours usage for his clients, `tickets-2026-12.csv` is the month's support tickets, and `mettle-client-summary-example.md` is a finished monthly client summary to match.
- `writing-monthly-client-summaries/`: the finished skill, `SKILL.md` and `example.md`. Share it with a client to install as is, use it as a model for their own version of the job, or rename it for a different recurring piece of work.
- `review-checklist.md`: what to check before approving a skill submitted for organisation publication.
- `skills-register.template.csv`: a blank register for published skills. Columns: `skill_name, owner, department, submitted_date, review_date, status, notes`.

This mirrors the Skills Studio course folder in the course-build repository. If that course changes its demo data, finished skill, or templates, update this folder too.
