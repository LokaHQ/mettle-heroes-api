# Skills Studio materials

Everything a Skills Studio participant needs: the practice data, the skill, and the templates the course leaves running. Take files from here, never from the internal course-build repository.

- `mettle-accounts/`: Callum Reid's client book for December. `customers.csv` is the account list, `hero-hours-2026-12.csv` is hero-hours usage for his clients, `tickets-2026-12.csv` is the month's support tickets, and `mettle-client-summary-example.md` is a finished monthly client summary to match.
- `writing-monthly-client-summaries-first-version/`: the skill as first built, before testing. Used when the demo starts at the testing step.
- `writing-monthly-client-summaries/`: the finished skill, after testing. Install it as is, use it as a model, or rename it for a different recurring job.
- `review-checklist.md`: what to check before approving a skill submitted for organisation publication.
- `skills-register.template.csv`: a blank register for published skills. Columns: `skill_name, owner, department, submitted_date, review_date, status, notes`.

This mirrors the Skills Studio course folder in the course-build repository. If that course changes its demo data, skill, or templates, update this folder too.
