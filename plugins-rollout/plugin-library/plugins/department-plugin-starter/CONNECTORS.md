# Connectors

The skills in this plugin name tool categories with a `~~` placeholder instead of a product, so the plugin works with whichever tool the team uses in that category.

Installing the plugin doesn't connect anything. On Team and Enterprise plans, an Owner adds a connector for the organisation first. Then each person connects their own account.

## Categories this plugin uses

Fill in one row per tool the weekly review reads from. Delete the rows you don't use.

| Category | Placeholder | We use | Who adds it |
|---|---|---|---|
| Work queue (tickets, requests, cases) | `~~work queue` | <tool> | <Owner name> |
| Chat | `~~chat` | <tool> | <Owner name> |
| Knowledge base | `~~knowledge base` | <tool> | <Owner name> |

## When nothing is connected

Every skill also works on files: an export from the work queue as a CSV, and documents attached or dropped into the project. The skills say which source they used.
