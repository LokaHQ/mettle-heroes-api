# Plugins & Department Rollout materials

Everything a participant needs. Take files from here, never from the internal course-build repository.

- `practice/`: Mettle & Co Customer Support's files for the demo and lab: the team brief, tools inventory, rollout brief, company profile, FAQ, December tickets and a client call transcript. Attach them to a project.
- `plugin-library/`: a starter plugin library. Copy its contents to the root of a private GitHub repository and an Owner can sync it into Claude (see its README). It holds two plugins:
  - `plugins/mettle-support-desk/`: the finished Customer Support plugin.
  - `plugins/department-plugin-starter/`: a blank starter for any department.
- `finished-example/`: what each demo step produces.

To install one plugin by hand, zip its folder (with `.claude-plugin/` at the top) and use Customize > Plugins > Add > Upload plugin.

This mirrors the Plugins & Department Rollout course folder in the course-build repository. Change both together.
